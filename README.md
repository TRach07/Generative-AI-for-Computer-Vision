# Generative AI for Computer Vision

This repository contains implementations of generative AI models for computer vision and natural language processing.

## Included Projects

### 1. [CNN-Based Generative Adversarial Network](./CNN-Based-Generative-Adversarial-Network/)
Implementation of a GAN based on convolutional neural networks for generating handwritten digit images (MNIST).

### 2. [Transformer for NLP](./Transformer-for-NLP/)
Text sentiment classification with BERT on the IMDb dataset.

### 3. [Variational Autoencoder (VAE)](./Variational-Autoencoder-VAE/)
Implementation of a VAE for image generation and reconstruction, with both basic and enhanced versions.

## Prerequisites

- Python 3.x
- TensorFlow
- NumPy, Matplotlib
- Transformers (for NLP project)

## Structure

Each project contains:
- A Jupyter notebook with the complete implementation
- A detailed README with architecture, usage, and results

See individual READMEs for more details on each project.
